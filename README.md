# PvZ DynMus

Dynamic, fully configurable music for **Plants vs. Zombies: Replanted**, as a [MelonLoader](https://github.com/LavaGang/MelonLoader) mod.

DynMus silences the game's own music and plays **your own `.wav` files** instead, while keeping the game's original
dynamic-music behaviour: when enough zombies are on screen a "horde" layer fades in, and it fades out again when the lawn
calms down. Fade lengths, loop points, alternating passes, per-level victory themes and more are configurable.

> 🇮🇹 Documentazione in italiano: [README.it.md](README.it.md)

**This repository contains no music and no game files.** You supply your own audio; the mod only plays what you put in its
folder, so only use audio you have the right to use. This is an unofficial fan project, not affiliated with or endorsed by PopCap
Games or Electronic Arts; *Plants vs. Zombies* and related names are trademarks of their respective owners.

## Requirements

- Windows
- Plants vs. Zombies: Replanted (Steam). Developed and tested against game version `1.5.1469_Steam`
- [MelonLoader](https://github.com/LavaGang/MelonLoader) 0.7.3 (Il2Cpp), run at least once so it generates `MelonLoader\Il2CppAssemblies`
- .NET SDK 6 or newer to build the mod (the project targets `net6.0`; tested with SDK 8)

The mod depends on the game's internal class names as generated by MelonLoader. A game update that renames them can break it.

## Install

Download the latest `PvZ-Replanted-DynMus-<version>.zip` from the [Releases](https://github.com/Hortus1556/PVZ-Replanted-DynMus/releases) page
and extract it into the game folder (the one containing `Replanted.exe`). It contains the mod, `Mods\PvZDynamicMusic.dll`, and one **empty**
folder per music inside `Mods\DynMus\` (`cd`, `cys`, `gw`, `mg`, `wg`, `rm`, `gtr`, `lb`, `cb`, `ub`, `bm`, `zg`); there is no audio in it.
Prefer to build it yourself? See [Build](#build).

1. Put your own `.wav` files in the matching folders of `<game folder>\Mods\DynMus\`. Subfolders are fine, in any layout: files are found by
   name anywhere under `DynMus` (if the same name appears twice, the one closest to the root wins).
2. Start the game. On first run the mod writes `Mods\DynMus\config.ini` and logs the files it found to the MelonLoader console.

The text inside `config.ini` and the mod's log messages are currently **in Italian**; this document describes every key.

## File names

Names are lowercase, without spaces. Only `<name>_base.wav` (or `<name>.wav`) is required for a music; everything else is optional.
If a music has no file, the game's **original** music keeps playing for it.

| File(s) | Used for |
|---|---|
| `cd.wav` | Main menu / Crazy Dave (also the fallback for Zen Garden) |
| `cys.wav` | Choose Your Seeds |
| `gw_base.wav`, `gw_horde.wav` | Grasswalk (day) |
| `mg_base.wav`, `mg_horde.wav` | Moongrains (night): the horde is a *different* track, crossfaded |
| `wg_base.wav`, `wg_horde.wav` | Watery Graves (pool) |
| `rm_base.wav`, `rm_horde.wav` | Rigor Mormist (fog) |
| `gtr_base.wav`, `gtr_horde.wav` | Graze the Roof (roof) |
| `lb.wav` | Loonboon (mini-games such as Wall-nut Bowling, Whack a Zombie) |
| `cb.wav` | Cerebrawl (Vasebreaker, I, Zombie) |
| `ub.wav` | Ultimate Battle (levels 1-10, 2-10, 3-10 and Column Like You See 'Em) |
| `bm.wav` | Brainiac Maniac (final boss) |
| `zg.wav` | Zen Garden and Tree of Wisdom (falls back to `cd.wav`) |
| `credits.wav` | Credits |

Other levels and mini-games (Zombotany, survival, …) simply play the music of the background they are on.

### Optional extra layers

`_alt`, `_horde_alt`, `_base_var`, `_horde_30` (and a layered `_horde`, which is the normal case) are kept in sync with `<name>_base.wav`:
they share its loop points, so they must have the **same duration** as the base (and should have the same channel count). A mismatch is
not rejected, it is only logged as a warning when the music loads or starts. `_vic`, and a `_horde` in crossfade mode, are independent
and can be any length.

| File | Behaviour |
|---|---|
| `<name>_alt.wav` | Plays in sync under the base but is audible on alternate loop passes: base, then alt, then base, … `_horde` overlays both. |
| `<name>_horde_alt.wav` | The horde to use while `_alt` is the audible pass (with `_base` the normal `_horde` plays). Needs `_alt` and `_horde`; ignored (with a log warning) in crossfade mode, which is the default for Moongrains (`mg`) or any music with `<prefix>.Crossfade = true`. |
| `<name>_base_var.wav` | An extra layer mixed **on top of** the base (not instead of it): audible only on the **first** loop pass, and never in adventure level 1-1. When a horde starts it comes back together with `_horde`, with the same fades. Master it like an overlay stem. |
| `<name>_horde_30.wav` | Added on top of `_horde`, only while a horde is active **and** more than 30 zombies are on screen (threshold configurable). |
| `<name>_vic.wav` | Victory theme for that music. Plays once, without looping, when you finish the level by collecting the reward, instead of the game's jingle. Uses the music volume from the game options. Only used when that music is itself replaced (`<name>_base.wav` or `<name>.wav` exists); otherwise, or if the file is missing, the game's jingle plays. |

## How it behaves

- **When a horde starts.** The mod does not guess: the game keeps running its own music state machine (its audio sources are muted
  rather than stopped) and the mod reads its burst state. In the original game the burst starts when 10 or more zombies are on screen
  and ends once fewer than 4 remain, after a minimum duration. Horde layers are meant for the five stage tunes that have a dynamic
  version in the game (gw, mg, wg, rm, gtr).
- **Fades.** The fade curves are the mod's own and are set in **seconds** in `config.ini`. Defaults: horde in 8 s / out 12 s, base
  (crossfade only) out 8 s / in 12 s.
- **Layered vs. crossfade.** By default a horde is layered over the base. For music the game marks as "replace" (Moongrains) the horde
  is a separate track: the base fades out, the horde fades in **from its own start** every time it re-enters from silence, and the base
  keeps running. Override with `<prefix>.Crossfade = true|false` in `[fade]`.
- **Loops.** Playback is sample-accurate, with cubic interpolation if a file's sample rate differs from the output rate.
  See `[loop]` below.
- **Pause.** Pausing the game pauses the music (and fades); victory themes keep playing.

## Configuration (`Mods\DynMus\config.ini`)

Keep the `Versione = 3` line: if it is lower than the mod's current version, `config.ini` is replaced with the new default and your old
file is kept next to it as `config.ini.vN.bak` (N = the old version). After editing, restart the game. Comments must be on their own line
(starting with `#` or `;`), never after a value.

**`[generale]`**

| Key | Meaning |
|---|---|
| `Versione` | Config format version. Do not change. |
| `MusicaNonMappata` | `original` (default) or `silence`. Applies to game tunes that are **not listed in `[mappa]`**: keep the original music or play nothing. A tune that is listed in `[mappa]` (even with an empty value) always keeps the original music when its files are missing. With the default `[mappa]` every tune is listed, so this only matters if you delete lines. |
| `Debug` | `true` enables verbose logging and the debug hotkeys below. |

**`[mappa]`** maps a game tune name to a file prefix. Several prefixes can be given, comma-separated; the first one that has files is used.
Leave a value empty to not replace that tune. Defaults:

```
TitleCrazyDaveMainTheme = cd         ChooseYourSeeds = cys
DayGrasswalk = gw                    NightMoongrains = mg
PoolWaterygraves = wg                FogRigormormist = rm
RoofGrazetheroof = gtr               PuzzleCerebrawl = cb
MinigameLoonboon = lb                Conveyer = ub
FinalBossBrainiacManiac = bm         ZenGarden = zg, cd
CreditsZombiesOnYourLawn = credits   DayGrasswalkCredits = credits
```

**`[fade]`** (seconds, numbers may use a decimal point or comma; values below 0.05 are raised to 0.05, so `0` is not an instant cut). Any key can be limited to one music with a `prefix.` in front, e.g. `mg.HordeFadeIn = 6`.

| Key | Default | Meaning |
|---|---|---|
| `HordeFadeIn` / `HordeFadeOut` | 8 / 12 | Horde (and `_horde_alt`, `_base_var`) fade in / out |
| `BaseFadeOut` / `BaseFadeIn` | 8 / 12 | Base fade out / in (crossfade music only) |
| `Horde30Zombie` | 30 | `_horde_30` is added with **more** zombies than this |
| `Horde30FadeIn` / `Horde30FadeOut` | same as horde | Fades of `_horde_30` |
| `<prefix>.Crossfade` | decided by the game | Force crossfade mode on or off for one music |

**`[loop]`** one line per music: `prefix = start, end`, in **sample frames** (samples per channel, as shown by audio editors such as
OpenMPT), without thousands separators. `end = 0` means the end of the file. Audio before `start` (an intro) plays once, then the
loop repeats from `start` to `end`. `_base`, `_alt`, `_horde`, … share the base's loop points. In crossfade mode the separate horde
track takes its own loop under the key `<prefix>_horde` (e.g. `mg_horde = 0, 0`).

Supported audio: WAV, PCM 8/16/24/32-bit or float 32/64-bit, mono or stereo, any sample rate.

## Debug hotkeys

With `Debug = true`, while the game window is focused (Windows only). `Ctrl+H/S/D/V` only work inside a level, `Ctrl+L` needs one of your tracks playing:

| Keys | Action |
|---|---|
| `Ctrl+H` | Trigger a horde: huge-wave message plus 25 zombies |
| `Ctrl+S` | Spawn 10 zombies |
| `Ctrl+D` | Remove all zombies |
| `Ctrl+V` | Drop the level-reward shovel: collect it to finish the level and hear `_vic` |
| `Ctrl+L` | Jump every layer to 4 seconds before the end of the loop, to check your loop point |

## Build

Clone the repository either inside the game folder (any folder name, e.g. `<game>\PvZ-Replanted-DynMus`: `GameDir` then defaults to the game folder) or anywhere else, and point `GameDir` at the game folder:

```
dotnet build PvZMusic.csproj -c Release -p:GameDir="D:\Games\Plants vs. Zombies - Replanted"
```

The game folder must contain `MelonLoader\Il2CppAssemblies` (start the game once with MelonLoader installed). No trailing backslash in `GameDir`.
The DLL is written to `bin\Release\net6.0\PvZDynamicMusic.dll` and copied to `<game>\Mods` if that folder exists (add `-p:CopyToMods=false` to skip the copy).

## Tests

Offline tests for the mixer, WAV decoder, config parser and file library (they do not need the game running, only the game folder
for one MelonLoader DLL; .NET 8 SDK):

```
dotnet run --project tests/DynMus.Tests -c Release
dotnet run --project tests/DynMus.Tests -c Release -- check "D:\Games\Plants vs. Zombies - Replanted\Mods\DynMus"
```

The second form (`check`) loads the `.wav` files of that folder read-only, using that folder's `config.ini` (its loop points only; `[mappa]` is ignored, it always inspects the standard prefixes), and prints the
layers it found for each standard music. It warns when `_alt`, `_base_var`, `_horde_alt` or `_horde_30` differ in duration or channel count
from the base, and shows whether `_horde` matches the base duration (required, except in crossfade mode). It does not check `_vic`.

If the repository is not inside the game folder, put `-p:GameDir="..."` **before** the `--` (everything after `--` goes to the program, not to MSBuild):

```
dotnet run --project tests/DynMus.Tests -c Release -p:GameDir="D:\Games\Plants vs. Zombies - Replanted" -- check "D:\Games\Plants vs. Zombies - Replanted\Mods\DynMus"
```

## How it works

- Harmony hooks on `AudioService.PlayFromOffset` (a tune started), `StopAllMusic`, and `PlayFoley` (victory jingles).
- The game's audio sources for the current tune are muted, not stopped, so its own burst logic keeps running and is read each frame.
- A small mixer runs in `OnAudioFilterRead` of an injected component on a silent `AudioSource`; tracks are decoded to float PCM in a background thread.
  The layers synced to the base (every layer except a crossfade-mode `_horde`, which has its own playhead) advance in lockstep (even while muted),
  so they stay in sync across loops, seeks and pauses.

## Known limitations

- **Memory.** Tracks are decoded to 32-bit float in RAM: about 23 MB per minute of 48 kHz stereo audio per file, and up to three
  music sets are kept cached. Music with four layers and long tracks can use several hundred MB; victory themes are cached separately (up to three more).
- WAV only. Windows only (the debug hotkeys use `user32`).
- Config comments and log messages are in Italian.
- The game updating its internals can break the hooks. At start-up the mod logs an error if the `PlayFromOffset` or `StopAllMusic` hook cannot be
  installed (the mod cannot work), or a warning if the `PlayFoley` hook cannot (only `_vic` is disabled).
